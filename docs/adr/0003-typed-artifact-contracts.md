# Agents push typed artifact contracts, never rendering code or chart-lib specs

Aurora exposes one MCP tool per artifact type (`push_markdown`, `push_mermaid`, `push_chart`, `push_image`, `push_video`), each with a structured input schema that *is* the contract. `push_chart` accepts a `chart_type` enum plus per-type data shapes — never raw ECharts options, Vega specs, or HTML. Rendering and styling (the house ECharts theme, markdown/mermaid styling) live entirely in aurora. The rejected alternatives were a single polymorphic tool (weaker schema enforcement, worse agent ergonomics) and accepting declarative viz specs like Vega-Lite (maximum power, but hands styling control back to the agent — the exact problem this feature exists to remove). Tool schemas are the only agent-facing surface; changing them breaks installed agents, so they are append-mostly.
