# Generation tools expose a whitelist-bounded model enum, not free-form model ids

The `model` parameter on the generation tools is a schema enum built from the operator's whitelist (code defaults, config-file override) rather than a free string validated server-side. The tool schema is the agent-facing contract (ADR-0003), and the enum makes the bounded surface self-documenting: agents see exactly which models are allowed — with live price hints — and never waste a call on a model that would be rejected. Config edits rebuild the enum per request, so curation needs no restart. The rejected alternative, tier-based selection (`quality: draft|high`) mapping to hidden models, would have kept a more stable schema but hid real cost and capability from the agent — the exact balance the whitelist exists to strike.
